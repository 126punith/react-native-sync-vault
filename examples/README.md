# Example Applications

This directory contains example applications demonstrating how to use react-native-sync-vault.

## Examples

### Todo App (Coming Soon)

A simple todo application demonstrating:
- Basic offline queue usage
- Automatic API interception
- Queue status monitoring
- Handling failed requests

### E-commerce App (Coming Soon)

An e-commerce application demonstrating:
- Product updates offline
- Order submission with conflict resolution
- Priority-based request queuing
- Custom API handlers

## Running Examples

Each example is a standalone React Native application. To run:

```bash
cd examples/todo-app
npm install
npx react-native run-ios
# or
npx react-native run-android
```

See `OfflineQueueExample.tsx` in the project root for a basic example.
